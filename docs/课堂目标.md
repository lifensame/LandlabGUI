# 课堂目标

这个工作台的主要使用者是地貌学或自然地理课上的本科生，以及带一节实验课的大学老师。

学生不写代码，也能在一节课内走完「抬升 → 汇流 → 下切 → 扩散」，看懂地形和坡度-面积，并交出一份实验记录。老师用同一份预设和讲义带完整班。

87 个组件、参数扫描、AI 助手和插件仍然留在菜单里，作为进阶，不再占据第一次启动。

## 一节课怎样算完成

- 学生打开软件后进入「课堂实验」，而不是先面对全部组件。
- 预设「课堂实验-河流下切」用小网格，默认不自动导出文件。
- 实验停靠条按真实操作推进：载入预设、四步顺序、跑完、先看地形再看坡度-面积、选择题、导出记录。连点「检查进度」不能跳过这些步骤。
- 讲义在 [课堂实验-河流下切.md](课堂实验-河流下切.md)。
