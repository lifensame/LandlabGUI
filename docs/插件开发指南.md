# Landlab GUI 插件开发指南

## 一、最简单的插件

在 `landlab_gui/plugins/` 文件夹里新建任意名字的 `.py` 文件，写入：

```python
from app.core.api import plugin
import numpy as np


@plugin(
    name="均匀抬升",
    category="构造抬升",
    params={
        "rate": {"type": "float", "default": 5e-4, "doc": "抬升速率 m/yr"},
    },
    doc="每个时间步给整个地形加一个固定抬升量",
)
def uniform_uplift(workspace, params):
    z = workspace.at_node["topographic__elevation"]
    z += params["rate"]
```

保存后在 GUI 菜单点 **插件 → 重载插件**，左侧组件树就会出现"均匀抬升"，
双击加入工作流即可使用，和内置 landlab 组件完全同等待遇（可保存进工作流 JSON、
可打包成预设）。

## 二、函数签名约定

插件函数固定为 `fn(workspace, params)`：

| 参数 | 类型 | 说明 |
|------|------|------|
| `workspace` | `app.core.workspace.Workspace` | 会话对象，见下表 |
| `params` | `dict` | GUI 表单收集的参数值 |

### workspace 上常用的属性和方法

```python
workspace.grid          # 当前 landlab 网格对象
workspace.at_node       # 等价 grid.at_node，按字段名读写数据
workspace.at_node["topographic__elevation"]   # 高程数组（numpy）
workspace.field_names() # 当前已有字段列表
workspace.log("...")    # 往 GUI 控制台打日志
workspace.components    # 最近一次运行实例化的组件 {id: 组件对象}
workspace.dt            # 当前时间步长(yr)。时间循环中引擎自动注入：
                        # 通量类过程（抬升/降雨等 m/yr）务必乘以它！
```

> ⚠️ 物理量约定：速率类参数（m/yr）每步只应施加 `速率 × workspace.dt`；
> 且空间过程只作用于 `grid.core_nodes`（内点），边界/出水口保持不动，
> 否则基准面随地形一起抬升、河流不下切。参考 `plugins/example_tectonic_uplift.py`。

## 三、params 参数表单定义

`params` 是字典：`参数名 -> {type, default, doc, choices}`

| type | 控件 | 值 |
|------|------|----|
| `"float"` | 数字输入框（支持 1e-5 科学计数法） | float |
| `"int"` | 整数输入框 | int |
| `"str"` | 文本框；有 `choices` 时变下拉框 | str |
| `"bool"` | 开关 | bool |
| `"field_ref"` | 字段下拉框（列出当前网格已有字段） | str |
| `"array"` | 文本框（JSON 或逗号分隔） | list |

`doc` 会显示为表单 tooltip。

## 四、执行时机

装饰器加 `run_in_loop=False` 可以把插件定义为"手动执行"功能（不进时间循环）：

```python
@plugin(name="导出高程CSV", run_in_loop=False)
def export_csv(workspace, params):
    np.savetxt("z.csv", workspace.at_node["topographic__elevation"])
```

默认 `run_in_loop=True`：插件加入工作流后每个时间步执行一次，
是构造抬升、随机降水这类"每步扰动"的正确姿势。

见 `plugins/example_tectonic_uplift.py` —— 移植自教程 erosion_model.py 的

## 六、调试建议

- 插件加载失败时错误会打印在 GUI 控制台（底部），并跳过该文件，不影响其他插件
- `重载插件` 会重新 import 所有插件文件，修改后无需重启 GUI
- 代码编辑器里可以先写好逻辑点"运行"实时调试，调试通过后点"另存为插件"
